Modern desktop experience for ZLT Co. built with Electron
 and packaged using Install Forge.

#Features
Modern desktop interface
Windows executable support
macOS DMG support
Portable-friendly builds
Custom splash screen
Native desktop integration
Tray icon support
Push notifications
Offline support
Auto updates
Deep linking support
Native file picker integration
Supported Platforms
Windows
Windows 10
Windows 11
Installation
Windows
Download the latest installer or portable EXE.
Run:
zLT_Co.exe



#Internet Connection

Some features require an internet connection because the app connects to:

https://zlt-co.web.app

Offline support may be available for selected features.
